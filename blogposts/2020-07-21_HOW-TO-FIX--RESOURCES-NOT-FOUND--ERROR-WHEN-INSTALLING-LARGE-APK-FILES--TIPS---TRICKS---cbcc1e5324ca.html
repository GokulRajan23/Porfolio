HOW TO FIX “RESOURCES NOT FOUND” ERROR WHEN INSTALLING LARGE APK FILES| TIPS & TRICKS |

All of us download games and apps from the playstore. But sometimes we tend to download large games through online websites or we ask our friends to share them to our smartphone. After installing and opening that app, we see messages like “Resources not found”. We think that the apk file is corrupt and tend to redownload it. Many of us have faced this problem. It is because large apps have an apk file and also a data file.

The data file should be properly placed in its specific location otherwise the app cannot use the resources present in the data file efficiently. The following steps will explain how to do this in a simple way.

The confusion occurs from the beginning itself. Many people does not even download the data file. They download only the apk file. The data file should also be downloaded.

These data files are generally large files and are always in a ZIP format when downloaded. We should extract the resources from this ZIP file using an extractor. we can use the extractor present in our mobile or we can use third party apps like Z Archiver.

Most common mistake: Many people download the data file, but they do not extract it. They themselves create a new folder (e.g : com.tencent.ig) and place the ZIP file in that folder. This is totally wrong.

This folder will be automatically created by the system when you extract the file correctly.

After extracting, we have to move this folder to its specific location. That is Internal storage>Android>Obb . This is the exact location.

Now you can install the apk and open it. The game/app will run smoothly.
